# Phase 3B-2 Public intake — Implementation Plan (v1, pendent d'aprovació)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** permetre que un tender públic arribi a l'anàlisi v3 i al workspace amb un paquet documental verificat, classificació global revisable, estructura amb provenance i un run de requisits global compartit de manera segura, sense inventar res i sense cap crida real a l'LLM en aquesta fase.

**Architecture:** quatre migracions additives (0058–0061); nou router d'operador `/platform/tenders/{id}/…`; classificació global produïda pel worker; resolutor de rols efectius; propostes d'estructura immutables + promoció via serveis interns; `run_basis`/`analysis_identity`/punter per empresa a l'extracció; frontera «cap paràmetre de tenant en tender públic»; UX amb estats honestos.

**Tech Stack:** FastAPI + SQLAlchemy async + Alembic (`apps/api`), Next.js 15 / React 19 (`apps/web`), pytest (SQLite + `--postgres`), vitest.

**Spec:** `docs/superpowers/specs/2026-10-07-public-intake-3b2-design.md` (auditoria: `…-3b2-audit.md`).

## Global Constraints
- Cap crida real a cap model: `LLM_PROVIDER=fake` a tot arreu; cap clau. Cap acció sobre el pilot (3200/8200, `licitacions_pilot_indaleccius`, worktree `Licitacions-pilot`).
- Cap dada de l'oracle copiada a cap DB que no sigui de test; fixtures públiques sintètiques sense dades personals.
- Enums nous amb CHECK (`in_values`); taules globals noves a `PUBLIC_TABLES`; taules tenant noves amb `company_id` NOT NULL.
- Valors exactes: `tender_document_origin ∈ {feed, owner_upload, operator_url, operator_upload}`; `contribution_status ∈ {not_applicable, pending_verification, verified, rejected}`; `governing_source_id` (FK sources, NULL si no és del feed); `DOCUMENT_OFFICIAL_HOSTS` default `["contractaciopublica.cat","contrataciondelestado.es","contrataciondelsectorpublico.gob.es"]`; trigger de revisió `document_intake`; event `SOURCE_TYPE_CHANGED_AFTER_REVIEW` (informatiu); `run_basis ∈ {real, simulation, unconfigured, gold}`; llindar `completed_empty` = run `real` ∧ 0 requisits ∧ 0 criteris ∧ `pages_analyzed ≥ 5` → `needs_review=true`; `ALLOW_SIMULATED_ANALYSIS=false`; `REQUIREMENTS_PRODUCT_PROFILE="v1"`; `LLM_ALLOWED_MODELS=[]` (model real només si `LLM_MODEL` hi és exactament); `LLM_MODEL_PRICES` obligatòria per a proveïdor real (`price_unknown`); `LLM_BUDGET_CANARY_USD=1`, `LLM_BUDGET_RUN_USD=3`, `LLM_BUDGET_PILOT_TOTAL_USD=10`; codis `budget_exceeded` (run) i `budget_exhausted` (quota); `LLM_TIMEOUT_SECONDS=300`; `LLM_MAX_RETRIES` al pilot = 0; error 422 `public_tender_canonical_only`; 403 `decision_required` (Preparar sense GO); 409 `requirements_outdated` també per corpus canviat; `origin` d'historial ∈ {source, internal, manual}.
- `unknown` mai es coacciona; cap valor conegut sense cita; cap escriptura a `TenderDocument.document_type` fora del connector que governa el document o del propietari en tender manual; `_sync_documents` només toca documents amb `governing_source_id` = la seva font (source ownership).
- Fora d'abast (decisions del propietari): propostes tenant (documents i rols), LLM d'estructura, documents privats en runs globals, rànquing, recurrència 1044, activació real d'LLM.
- Codi backend en català sense accents; UI en català amb accents. NO COMMIT fins a aprovació.

## Review Focus
1. Una empresa B que demana l'anàlisi d'un tender públic ja analitzat per A amb `document_ids`/`force` ha de rebre 422 i mai substituir el run canònic.
2. Un run `fake` COMPLETED (0 requisits) no pot ser `is_current` ni aparèixer com a «analitzat» a cap pantalla.
3. Un document `pending_verification` no entra a cap selecció (processament per defecte, classificació, quota, cites) i la seva arribada no canvia cap empremta.
4. Un sync complet posterior del feed no retira un document `operator_url`/`operator_upload` ni en sobreescriu nom/tipus.
5. Una revisió `document_processing`/`document_intake` apareix sota «Processament intern», mai sota «Publicat per la font».
