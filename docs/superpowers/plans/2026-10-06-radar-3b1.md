> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Primera font pública operacional (PLACSP sindicació agregada 1044, nova fila `Source`) sobre el pipeline CODICE existent, amb sincronització observable i amb lock, regles d'ordre/conflicte/absència no destructives, presència a la font sense estat `withdrawn`, base de l'anàlisi `analysis_affecting`, catàleg complet «Totes» amb cerca normalitzada i filtres, i la UI mínima.

**Architecture:** Reutilització íntegra d'`app/ingestion/placsp/*`, `SourceRecord`/`Tender`/`TenderRevision` i `IMPACT_MATRIX`. Afegits: registre de fonts; client amb condicionals; parser/normalitzador per al 1044 (`ID_OC_PLAT`, `source_metadata`); servei amb guarda d'ordre, conflictes, làpides com a presència de font, absències només des de publicació completa posterior; `app/ingestion/sync.py` (lease, run, salut, retry, CLI amb `--every`) separat de `work_jobs`; `latest_analysis_affecting_revision`; `search_text` normalitzat + `TenderFilters` ampliat + índexs PG; web «Totes».

**Tech Stack:** FastAPI, SQLAlchemy async, Alembic (PG 18 / SQLite), httpx `MockTransport`, defusedxml, Pydantic v2; Next.js 15 / React 19, vitest.

**Spec:** `docs/superpowers/specs/2026-10-06-radar-3b1-design.md` (v2; companys `…-radar-3b1-sources.md`).

## Global Constraints
- Cap camp inventat; `NULL`/`unknown` + codi cru (spec §3). Res específic de PLACSP com a columna de `Tender`: va a `source_metadata` (claus tancades).
- Una publicació amb `updated` anterior a l'estat canònic mai regressa el tender; mateix `updated` + hash diferent = conflicte observable, no destructiu (spec §4.2).
- Làpides = presència a la font (`source_removed_at`, `SOURCE_ENTRY_REMOVED/RESTORED`, impacte `informational`); **cap** `TenderStatus.WITHDRAWN`; només una dada explícita de la font canvia `status` (spec §4.3).
- Absències de documents/lots només des d'una publicació completa posterior del mateix tender; mai per pàgina fallida, `next` incomplet o sync `partial`; cap delete físic (spec §4.4).
- Base de l'anàlisi = última revisió amb `requirements_affecting` o `compliance_affecting`; `app/analysis/*` intacte (spec §4.5).
- Sync de font separat de `work_jobs` (`tender_id` continua NOT NULL); lease per font; `success/partial/failed`; sense LLM (spec §6).
- «Totes»: cap `INNER JOIN` amb `company_tender_matches`, cap `min_score`, ordre per defecte `published desc nulls last, first_seen_at desc, id` (spec §7.1).
- Normalització de cerca a l'aplicació (NFKD, sense diacrítics, casefold, espais estables), idèntica per a `search_text` i `q`; sense `unaccent` (spec §7.2).
- Cap descart humà, cap rànquing nou (spec §13). Cap taula `company_tender_dismissals`.
- Migracions `0055_radar_ingestion` (additiva) i `0056_radar_search` (PG; `pg_trgm`), reversibles (spec §9).
- Backend en català sense accents; UI amb accents. `LLM_PROVIDER=fake`. Cap ingestió massiva; cap acció al pilot; cap commit fins a la revisió final.
- Valors exactes: `Source.code = "placsp_agregadas"`, nom `"PLACSP · plataformes agregades"`, `base_url = "https://contrataciondelsectorpublico.gob.es/sindicacion/sindicacion_1044/PlataformasAgregadasSinMenores.atom"`; `OVERLAP_HOURS = 48`; lease 15 min; `ProcessingStatus.CONFLICT = "conflict"`; `ChangeCode.SOURCE_ENTRY_REMOVED = "SOURCE_ENTRY_REMOVED"`, `SOURCE_ENTRY_RESTORED = "SOURCE_ENTRY_RESTORED"`; trigger `"tombstone"`; `parser_version = "placsp-v2"`; `q` màxim 6 termes; `limit` 25 / màx 100.
